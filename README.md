# petpet-bot
[Maubot](https://maubot.xyz) plugin for generating "petpet" GIFs ([source](https://tenor.com/view/petpet-transparent-hand-nothing-nothingness-gif-21537420)).

To use, either
1. respond to a message containing an image with the message `!petpet`, or
2. write `!petpet <user>` where `<user>` is a valid Matrix user ID.
